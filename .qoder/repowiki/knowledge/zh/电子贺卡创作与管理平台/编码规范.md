- 所有业务逻辑与 API 调用均收敛于 `src/utils/supabase.ts` 中的命名空间对象（如 `auth`, `templates`, `cards`），组件不直接调用底层 SDK。
- 状态更新遵循 Zustand 的不可变模式，在 `set` 回调中通过展开运算符 `{ ...state, updates }` 确保状态引用的更新。
- 页面组件通过自定义 Hook `useAuth` 获取认证状态，并在需要保护的页面或组件中检查 `isAuthenticated` 或 `isAdmin` 标志。
- 编辑器交互采用“选中-操作”模式，通过 `selectedElementId` 状态联动 `Canvas` 的视觉反馈与 `PropertyPanel` 的属性编辑。
