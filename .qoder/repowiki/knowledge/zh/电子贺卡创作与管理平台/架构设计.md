- **技术栈**: 采用 Vite + React 18 + TypeScript 构建，使用 Tailwind CSS 进行样式设计，Zustand 进行全局状态管理（编辑器状态、用户会话、模板库），React Router v7 处理前端路由。
- **数据层抽象**: `src/utils/supabase.ts` 封装了 Supabase 客户端，并实现了 Mock 模式（当环境变量缺失时自动降级为内存模拟数据），支持认证、模板 CRUD、卡片管理及后台管理接口。
- **模块化结构**: 
  - `src/components`: 按功能域划分为 `editor` (画布、工具栏、属性面板)、`admin` (后台布局)、`common` (页头页脚) 和 `templates` (筛选与展示)。
  - `src/pages`: 对应路由的页面级组件，包括公开页面（首页、编辑器、预览）和受保护的管理员页面。
  - `src/store`: 使用 Zustand 拆分为 `useEditorStore` (编辑状态), `useTemplatesStore` (模板筛选), `useUserStore` (用户与会话)。
- **权限控制**: 通过 `src/hooks/useAuth.ts` 结合 `AdminRoute` 包装器实现管理员路由保护，利用 Supabase Auth 元数据 (`is_admin`) 区分普通用户与管理员。
